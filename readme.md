# Road to 90 PWA

This is an installable Progressive Web App.

## Easiest deployment options

### Netlify Drop
1. Unzip this folder.
2. Go to Netlify Drop in Safari/desktop browser.
3. Drag the entire `road_to_90_pwa` folder onto the page.
4. Netlify gives you a public HTTPS URL.

### GitHub Pages
1. Create a new repository.
2. Upload these files to the repository root.
3. In Settings > Pages, publish from the main branch.
4. Open the resulting HTTPS URL.

## Add to iPhone Home Screen
1. Open the deployed HTTPS URL in Safari.
2. Tap Share.
3. Choose Add to Home Screen.
4. Tap Add.

The app will then launch in standalone mode.

## Notes
- XP is saved locally on that device/browser.
- The official Road to 90 score remains evidence-based in ChatGPT.
- This version is intentionally simple and can be expanded with badges, weekly challenge setup, evidence uploads, charts, and automatic score syncing later.
